# Female joint patch spatial tile viewer

The workflow generates a self-contained HTML viewer alongside the JSON audit. It colors sampled endpoint-patch triangles by their normalized 4×4 spatial tile and provides controls for side, joint relation, patch A/B, and donor/host source. Users can rotate the sampled mesh by dragging and inspect tile-level descriptors.

The viewer is geometric evidence only. It does not identify anatomy, infer cartilage, or modify production geometry. It displays sampled triangles, not the full-resolution source mesh.
